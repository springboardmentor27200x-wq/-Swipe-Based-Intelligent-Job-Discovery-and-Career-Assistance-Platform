# SwipeX – Swipe-Based Intelligent Job Discovery and Career Assistance Platform

SwipeX is an intelligent recruitment and career assistance platform designed to simplify the job discovery and recruitment process.

The platform provides separate interfaces for Job Seekers and Recruiters and includes resume analysis, ATS scoring, job recommendations, application tracking, notifications, and recruiter management features.

## Features

### Job Seeker
- User Registration and Login
- Browse Available Jobs
- Swipe / Apply for Jobs
- Save Jobs
- View Recommended Jobs
- Resume Upload
- ATS Resume Score
- Resume Skill Extraction
- Resume–Job Match Analysis
- Missing Skill Suggestions
- Job Recommendations
- Application Tracking
- Notifications
- Profile Management
- Job Analytics

### Recruiter
- Recruiter Registration and Login
- Recruiter Dashboard
- Add New Jobs
- View Posted Jobs
- View Applicants
- Accept or Reject Applications
- Application Notifications
- Recruiter Analytics
- Profile Management
